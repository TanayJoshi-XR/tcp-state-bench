# Provenance

The files in `protocol/`, `experiments/netsim.py` and `tests/test_congestion.py` are copied
from https://github.com/TanayJoshi-XR/mini-tcp at commit `c946a57` (Phase 5), with the
ground-truth label logger from branch `label-logger-pilot`, commit `da9912b`
(`protocol/mini_tcp.py`, `experiments/netsim.py`, `experiments/labels.py`,
`experiments/label_run.py`, `tests/test_labels.py`).

This repository is the working copy for the benchmark. The mini-TCP repository stays as the
finished showcase project; changes made here are not automatically mirrored there.
